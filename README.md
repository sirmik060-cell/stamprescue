# StampRescue v0.5 — Sirmik Edition

Программа для восстановления отсканированных документов: убирает печати и
штампы, восстанавливает фон и позволяет вставить новую печать (сделать её в
конструкторе или вставить готовую картинку). Работает полностью офлайн,
ничего никуда не отправляет.

## Требования

- Windows 10 / 11, 64 бита
- ~700 МБ на диске (всё нужное, включая модель ИИ, входит в установщик)
- Интернет не нужен

## Установка

1. Запустите `StampRescue-0.5-setup.exe` (свежий установщик всегда в разделе
   **Releases** этого репозитория).
2. Выберите папку (по умолчанию `%LOCALAPPDATA%\Programs\StampRescue`, права
   администратора не нужны) и нажмите «Далее». Программа создаст ярлык на
   рабочем столе и в меню «Пуск».
3. Запуск: ярлык «StampRescue» или `StampRescue.exe` в папке установки.

Удаление: «Параметры → Приложения → StampRescue → Удалить» (или uninstall
из папки программы).

### Если запускаете из исходников

Модель `models/lama.onnx` (~200 МБ) в git не кладётся — файл слишком большой
для GitHub. Варианты: взять её из установленной программы (папка
`_internal\models\`), скачать установщик из Releases и распаковать, или
собрать самому: `python tools/convert_lama_to_onnx.py models/lama.onnx` —
скрипт сам скачает оригинальные веса LaMa (196 МБ):
https://github.com/enesmsahin/simple-lama-inpainting/releases/download/v0.1.0/big-lama.pt
Подробности — в `models\README.txt`. Для запуска из исходников положите
`lama.onnx` в папку `models/` рядом с `main.py`.

## Как пользоваться (основной сценарий)

1. **📂 Открыть** — загрузите скан (PNG/JPG) или PDF. Листается кнопками ◀ ▶.
2. Выберите режим на верхней панели:
   - **ФОН** — рамка выделяет участок, ползунок восстанавливает фон
     (закрашивает выделенное «бумажным» фоном).
   - **ПЕЧАТЬ** — удаление печати моделью ИИ (LaMa):
     1. **🖱 Рамка** — обведите печать (или **✏️ Кисть** — обведите её по
        контуру; **🧽 Ластик** — убирает ошибки кисти).
     2. Пипеткой возьмите **СВОЙ** цвет — кликните по чернилам вашей печати.
     3. (Необязательно) пипетки **ЧУЖОЙ** (до 3 эталонов) и **ФОН** — чтобы
        соседние печати/текст не задели.
     4. Подвигайте «Допуск цвета», нажмите **👁 Показать маску**: зелёным
        видно, что будет удалено. Кистью/ластиком можно подправить маску.
     5. **🧹 Очистить печать** — программа уберёт выделенное и восстановит
        фон/текст под ним. **↶ Отменить** — откат.
   - **ВСТАВКА** — вставьте новую печать: **🏗 Конструктор** (справа вверху)
        создаёт печать по слоям, либо вставьте готовый PNG.
3. **💾 PNG / 💾 PDF** — сохранение результата. В режиме ПЕЧАТЬ есть
   «Вырезать в PNG» — вырезает только контур чернил без белого фона.

Подсказки по текущему шагу всегда видны в нижней строке программы.

## Печати и пресеты

В **Конструкторе**: форма, размер (мм), слои (кольца, текст по дуге, центр,
картинки/звёзды), цвет, «шум» печати. **💾 Пресет** сохраняет настройку в
JSON, **📂 Пресет** открывает список готовых типовых печатей (папка
`presets` рядом с программой: ООО основная 38 мм, ООО для документов 33 мм,
«Копия верна» 30 мм, ИП 38 мм). Вы можете добавить свои пресеты в эту папку.
**Экспорт PNG** — готовая печать прозрачным фоном для режима ВСТАВКА.

## Часто задаваемые вопросы

- **Модель ИИ не найдена?** Папка `models\lama.onnx` лежит внутри папки
  программы. При запуске переносной копии с флешки ничего делать не нужно —
  модель ищется рядом с exe.
- **Заставка мешает** — уберите/создайте переменную окружения
  `STAMPRESCUE_NO_SPLASH=1` (или просто кликните по заставке — она закроется).
- **Что такое «свой/чужой» цвет?** «Свой» — чернила той печати, которую
  убираем; «чужой» — печати/чернила, которых нельзя касаться. Программа
  сравнивает оттенок и насыщенность, а не просто «красный/синий».
